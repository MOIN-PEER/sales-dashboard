# API reference

All endpoints are `GET` and return JSON (except the CSV export). Interactive documentation is generated by
FastAPI at **http://127.0.0.1:8000/docs** while the server is running.

## Shared filters

Every dashboard endpoint accepts the same optional query parameters, so all charts describe the same slice of data.

| Parameter  | Example        | Notes                                                           |
|------------|----------------|-----------------------------------------------------------------|
| `start`    | `2025-01-01`   | First day (inclusive). Default: first day in the data.          |
| `end`      | `2025-12-31`   | Last day (inclusive). Default: last day in the data.            |
| `region`   | `London`       | Must be one of `/api/filters` regions, otherwise **400**.       |
| `channel`  | `Online`       | `Online` or `In-store`.                                         |
| `category` | `Electronics`  | Product category.                                               |

Invalid dates or parameter types return **422**; `start` after `end` returns **400**.

## Endpoints

| Endpoint | Extra parameters | Returns |
|----------|------------------|---------|
| `/api/health` | | `{"status": "ok", "sales_lines": 48994}` |
| `/api/filters` | | Allowed regions, channels, categories and the date range |
| `/api/kpis` | | Revenue, profit, margin %, orders, units, average order value, and % change against the previous comparable period |
| `/api/revenue-trend` | `grain` = `day` / `week` / `month` / `quarter` | Revenue, profit and orders per period |
| `/api/regions` | | Revenue, profit, orders, margin % and share % per region |
| `/api/categories` | | The same per product category, plus units |
| `/api/channels` | | Revenue, profit and orders per channel |
| `/api/top-products` | `limit` (1-40), `sort` = `revenue` / `profit` / `units` | Top products with margin % |
| `/api/export/products.csv` | | All products for the current filters as a CSV download |

### Previous period rule

* Whole calendar months are compared with the same number of whole months before
  (2025 vs 2024, Q4 vs Q3, March vs February).
* Any other range is compared with the same number of days immediately before it.
* If there is no data in the previous period, the change is `null` and the card shows "no comparison period".

## Examples

```bash
curl "http://127.0.0.1:8000/api/kpis?start=2025-01-01&end=2025-12-31"
curl "http://127.0.0.1:8000/api/revenue-trend?grain=quarter&channel=Online"
curl "http://127.0.0.1:8000/api/top-products?limit=5&sort=profit&region=Scotland"
curl -o products.csv "http://127.0.0.1:8000/api/export/products.csv?category=Beauty"
```
